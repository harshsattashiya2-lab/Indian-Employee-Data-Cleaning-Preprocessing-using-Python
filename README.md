Indian Employee Data Cleaning & Preprocessing

This project demonstrates how to clean and preprocess a real-world employee dataset using Python, Pandas, and NumPy. The dataset contains missing values, duplicate records, infinite values, negative salaries, and salary outliers. The cleaning process prepares the data for further analysis, visualization, or machine learning.

FEATURES :-

Load employee dataset from CSV
Identify missing values
Replace infinite (inf) values with NaN
Fill missing salary values using the mean
Fill missing performance ratings using the median
Fill remaining missing values in numeric columns
Remove duplicate records
Replace negative salary values with the average salary
Detect and remove salary outliers using the 3-Standard Deviation method
Export the cleaned dataset to a new CSV file

TECHNOLOGIES USED:-
Python 
Pandas
NumPy

Output
